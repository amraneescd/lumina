# Base — Social Media Recording Guide

## Hero Moments for Screen Recording

### 1. Block Editor Magic (15-20 seconds)
**Setup**: Open any page with the block editor

**Actions**:
1. Click in the editor
2. Type `/` to open slash command menu
3. Arrow down to "To-do" → hit Enter
4. Type "Review homepage wireframes" → hit Enter
5. Type `/` again → select "Heading 2" → type "Sprint Goals"
6. Type `##` at start of line → watch it convert to Heading 2
7. Type `[]` → watch it convert to checkbox

**Recording Tips**: Zoom in to 125%, focus on the cursor area

---

### 2. Kanban Drag & Drop (10-15 seconds)
**Setup**: Navigate to Tasks database → Board view

**Actions**:
1. Grab a task card from "In Progress" column
2. Drag it to "Done" column
3. Watch the smooth ghost preview and snap animation

**Recording Tips**: Show the full board, 60fps for smooth drag

---

### 3. Database View Switch (8-10 seconds)
**Setup**: Open Projects database

**Actions**:
1. Click "Table" tab → show table view
2. Click "Board" tab → show kanban board
3. Click "Calendar" tab → show calendar
4. Click "Gallery" tab → show gallery cards

**Recording Tips**: Quick cuts between views, no reload flash

---

### 4. Dark Mode Toggle (5-8 seconds)
**Setup**: Any page, light mode

**Actions**:
1. Click user avatar → Settings
2. Click "Dark" theme option
3. Watch entire app transition smoothly
4. Click "Light" to switch back

**Recording Tips**: Full screen capture, show the contrast

---

### 5. Command Palette (8-10 seconds)
**Setup**: Any page

**Actions**:
1. Hit Cmd+K (or Ctrl+K)
2. Type "project" 
3. Arrow down to "Go to Projects"
4. Hit Enter
5. App navigates to Projects database instantly

**Recording Tips**: Show the keyboard shortcut overlay

---

## Export Settings

- **Resolution**: 1920x1080 (1080p)
- **Frame Rate**: 60fps
- **Format**: MP4 (H.264)
- **Duration**: Each clip under 30 seconds
- **Background Music**: Optional, subtle lo-fi or ambient

## Posting Platforms

| Platform | Format | Tips |
|----------|--------|------|
| Twitter/X | MP4, <2:20 | Add captions, thread with context |
| TikTok/Reels | 9:16 vertical | Crop to focus area, add trending audio |
| LinkedIn | MP4, <10min | Professional caption, tag features |
| YouTube Shorts | 9:16 vertical | Title cards, end screen with CTA |
